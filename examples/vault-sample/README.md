# 示例 Vault

> 这是一个**虚构的示例 vault**，用于演示 agent-memory-driven-evolution 的记忆归档结构。
> 所有内容均为演示用途，不涉及任何真实人物或项目。

## 目录结构

```
HermesMemory/                    # 冷记忆 vault（Obsidian）
├── INDEX.md                     # 全局索引（自动维护）
├── daily/                       # 每日总结
├── projects/                    # 项目归档（自动分类）
│   └── website-backend/         #   示例项目
├── preferences/                 # 用户偏好
├── incidents/                   # 错误/教训
└── .obsidian/                   # Obsidian 配置
```

## 演示内容

| 路径 | 说明 |
|------|------|
| `daily/2026-06-08-示例-会话总结.md` | 每日总结示例 |
| `projects/website-backend/2026-06-08-技术调研.md` | 项目归档示例 |
| `projects/website-backend/TIMELINE.md` | 项目时间线示例 |
| `preferences/2026-06-08-用户硬规则.md` | 偏好学习示例 |
| `incidents/2026-06-08-部署超时.md` | 错误记录示例 |

## 使用

1. 用 Obsidian 打开本目录
2. 安装 Smart Connections 插件（语义搜索）
3. 日常对话的记忆会自动写入对应的子目录

## 注意

- 本样例全部为虚构内容，仅用于展示 vault 结构
- 你可以直接删除本样例，创建自己的记忆库
