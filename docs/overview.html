🎯 为什么需要这套方案

❌ 上下文会爆
system prompt 注入每轮都跑，token 贵、慢、易超窗口
❌ 知识会丢
会话结束 = 信息消失。隔天就忘了昨天讲过啥
❌ 找不到历史
"上次讲过 X 吗" 全靠 grep，不直观
❌ 不成体系
项目踩坑、偏好、承诺散落各处

方案目标

  • ✅ 零丢失 所有上下文自动存档
  • ✅ 自动分层 不需手动提醒
  • ✅ 语义搜索 不依赖精确关键词
  • ✅ 可视化 Obsidian 友好的 vault
  • ✅ 可传承 别的 agent 也能维护

🔄 Vault 后处理（5 件事）

每次归档后 自动跑 vault_postprocess.py

1️⃣ 反向链接注入
扫所有 .md 提取标题，给每个文件底部追加 ## 相关链接 段（[[INDEX]] + 同目录文件）
2️⃣ 项目时间线生成
遍历 projects/*/，生成 TIMELINE.md（按文件名日期排序）
3️⃣ INDEX.md 维护
自动重写：完整目录树 + 项目列表 + 统计 + 快捷键表
4️⃣ README.md 维护
vault 门面：6 项统计 + 最近 5 条归档 + 完整结构图
5️⃣ 错误统计（ERRORS.md）
读 .checkpoints/errors.json，生成按类别分布 + 时间线 + Top 5 报告
"归档 → 后处理 一次命令完成所有" —— 零维护

🐞 故障排查

现象原因修复
smart_archive 不写文件标签为空 + 启发没匹中显式传标签
反向链接没出现没跑 vault_postprocesspython3 ~/.hermes/scripts/vault_postprocess.py
热记忆计数不准没调 update_hot_used写完热记忆后调一次
Obsidian 看不到 vaultapp.json 缺失 / vault 未注册写 app.json + obsidian.json 注册
Smart Connections 不工作Restricted Mode 没关删 community-plugins.json 重启
daily 快照被误归到 projects标题/内容含已有项目名传 "daily" 标签（绝对优先）
skill_manage create 假成功系统 bug用 write_file 兜底 + skill_view 验证
"找不到 = 说不知道，不编" —— 诚实原则

  "https://github.com/obsidianmd/obsidian-releases/releases/latest/download/Obsidian.dmg"

2. 注册 vault

# 在 Obsidian 里：Open folder as vault → ~/Documents/HermesMemory
# 或者配置 obsidian.json 注册

3. 用起来

# 装语义搜索插件
mkdir -p ~/Documents/HermesMemory/.obsidian/plugins/smart-connections
cd ~/Documents/HermesMemory/.obsidian/plugins/smart-connections
curl -L -o main.js "https://github.com/brianpetro/obsidian-smart-connections/releases/latest/download/main.js"

# 启用
